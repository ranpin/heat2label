heat2label

把模型内部的热力图变成伪 bounding-box 标注，让图像无需手画每个框就能（预）标注。两条独立的臂——同一思路的两种实现。

GitHub 源码 ↗

演示

预计算演示 · 两个模型都太重、无法在浏览器内运行 · 复现见仓库。切换 DAAM / Grad-CAM++ 两条臂，选择样本，走完整「热力图 → 伪框」管线。


    


    
    

      
评测结果

      
两条臂是同一思路（热力图 → 伪框）的两种独立实现，下表对比各自的热力图来源、产出形态与适用域。

      

        
DAAM（daam2label）Grad-CAM++（cam2label）

        
热力图来源Stable Diffusion 交叉注意力（DAAM），文本 prompt 驱动ImageNet 预训练 ResNet-101 上的 Grad-CAM++，预测驱动

        
是否生成图像是——SD v1.4 img2img 增强，再给输出打框否——给已有图像打框

        
适用域驾驶场景长尾类（motorcyclist、truck）COCO zero-shot 划分（65/15、48/17）

        
框类型轴对齐 bbox → label.json（COCO 风格）旋转框（cv2.minAreaRect）画在图上

        
算力建议 CUDA GPU ≥ 8GBCPU 即可

        
入口demo_daam.py（argparse CLI）gradcam/cam.py、gradcam/test.py

      

      
两臂不共享代码，是同一技巧的两种独立实现，并列保留以便对比；产出的每个框都是伪标注、仍需人工复核（定位是预标注 / 数据增强助手，非生产级标注器，详见仓库 README）。本表对比两臂的产出特征，非定量精度基准。

    


    
    

      
核心方法

      
两条臂共享同一条管线，只在「热力图从哪来」和「服务什么域」上不同。

      
图像 ──► 模型前向 ──► 热力图 ──► 阈值化 ──► 区域 ──► 框
                │                                    │
       (SD 交叉注意力 | Grad-CAM++)        (BFS 岛提取 | 轮廓 + minAreaRect)

      

        
臂方法细节

        
DAAMSD v1.4 img2img 跨 seed 增强驾驶场景初始图 → 逐词交叉注意力热力图（DAAM）→ 阈值化 + BFS 岛提取 → 长尾类的轴对齐伪框 → 输出 COCO 风格 label.json

        
Grad-CAM++ImageNet 预训练 ResNet-101 → Grad-CAM++ 类激活热力图 → 阈值化 → cv2.minAreaRect 拟合旋转框
